Add your own photos here using these exact filenames so they appear automatically:

tanvi-hero.jpg     -> Hero section photo (portrait, min. 1000x1300px recommended)
about.jpg          -> About section photo (portrait, min. 900x1200px recommended)
content-01.jpg      through
content-10.jpg     -> Portfolio grid images (any of your outfit/reel/fit-check photos)

You can edit titles, descriptions and categories for each portfolio image
inside script.js, at the top, in the PORTFOLIO_ITEMS array.

Until real images are added, the site shows an elegant placeholder
automatically, so nothing breaks.
